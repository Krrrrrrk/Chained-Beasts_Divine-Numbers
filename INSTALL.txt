Divine Numbers 0.2.1

Requires Steam build 26231777 and an existing BepInEx IL2CPP installation.
No Foundation dependency.

Close the game. Copy the included BepInEx folder into the Chained Beasts folder.
The only plugin file added/replaced should be:
BepInEx/plugins/ChainedBeasts.DivineNumbers/ChainedBeasts.DivineNumbers.dll

Hold either Ctrl key for a separate numbers box. Character select, character
info, character-details skill rows and trainer cards retain their usual behavior.
In potion/healer shops, hold Ctrl anywhere over the offer card, including the
header, border, empty space and price. In surgery and Codex screens, hover the
displayed description text with Ctrl. New labels can take up to half a second.
Release Ctrl to hide it. Shift keeps the game's normal status explanations.

Controller: open a supported info/menu screen and click the right stick (R3)
to toggle the numbers box. It follows the native highlighted item or your
character-select description. Click R3 again to turn it off. Closing the info
menus, losing application focus or disconnecting that pad clears the toggle.
The native shoulder-button controls keep working. Rows without native controller
focus still require mouse/Ctrl. Controller navigation needs manual testing.

Optional configuration after the first launch:
BepInEx/config/local.chainedbeasts.divinenumbers.cfg
[Input]
ControllerToggleButton = RightStickClick
Other choices: LeftStickClick, Disabled. Restart to apply changes.
The older 0.2.0 DLL has no controller toggle. Check the loaded version in
BepInEx/LogOutput.log if R3 does nothing; the controller update must be installed
and the game restarted before it can respond.

Includes 206 cards: 50 skills/variants, 134 affliction severity entries,
18 purchases and four shared statuses. See AUDIT.md for findings and limits.
Unknown/locked descriptions have no guessed card. Numbers are usually base
values; final results depend on modifiers. One training-only entry is unresolved.

Original descriptions and combat behavior are preserved. Smaller type and padding
remain. Build/offline checks pass; expanded UI needs manual testing.
See MANUAL-CHECKS.md. No game was launched or automated for this update.

To uninstall, close the game and remove only this mod's DLL.
Changed audited game files disable the mod until re-audited.
