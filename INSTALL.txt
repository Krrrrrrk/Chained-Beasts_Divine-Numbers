Divine Numbers 0.1.1 - TEST BUILD

Requires Chained Beasts Steam build 26231777 and an existing BepInEx IL2CPP installation.
This mod has no Foundation dependency.

Close the game. Copy the included BepInEx folder into your Chained Beasts game folder.
The only plugin file added should be:
BepInEx/plugins/ChainedBeasts.DivineNumbers/ChainedBeasts.DivineNumbers.dll

On character select, highlight a supported beast variant and hold either Ctrl key.
You can also inspect its character-info tooltip or hover its row in the lobby
character-details list. A separate box shows the researched numbers.
Release Ctrl to hide it. Shift keeps the game's normal status explanations.

Included entries: Proud Lion, Lethal Eagle, Mighty Bear.
Other skills/afflictions have no numeric box yet. Locked variants and Codex pages
have no numeric card. Version 0.1.1 uses smaller text and explicit inner padding.

The original descriptions and combat behavior are preserved.
Build and offline checks pass. The revised layout and character-select input need
manual confirmation. See MANUAL-CHECKS.md.

To uninstall, close the game and remove only this mod's DLL.
The mod disables itself if the game binary changes until its data is re-audited.

Source: https://github.com/Krrrrrrk/Chained-Beasts_Divine-Numbers
